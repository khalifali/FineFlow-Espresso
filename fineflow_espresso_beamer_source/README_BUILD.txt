FineFlow--Espresso Beamer presentation
======================================

Main source:
  fineflow_espresso_beamer.tex

Compile from this directory with:
  latexmk -pdf fineflow_espresso_beamer.tex

All externally included graphics are stored in:
  figures/

The diagrams explaining the physical mechanisms, one-dimensional domain,
finite-volume mesh, workflow, and experimental plan are editable TikZ code
inside the main TeX file.

The numerical result figures were generated by the accompanying
FineFlow--Espresso Python solver. The displayed parameter set is illustrative
and has not yet been experimentally calibrated.

2026-09-11 revision: 31 slides with new Darcy and Kozeny-Carman results.
Run the three-case study from the solver directory:
  python compare_closures.py
The closure_comparison directory contains CSV, NPZ, JSON and single-axis plots.
The deck retains illustrative parameters and does not claim physical validation.

Presenter transcript (slide left, transcript right):
  python -m pip install pymupdf
  python build_transcript.py
Run this after recompiling the main PDF. The editable transcript is transcript.json.
The script also produces a source archive. All restored TikZ diagrams remain editable.
